# Paracore 4.2.1 (Patch Release)

## Overview
What started as a simple patch release evolved into a major architectural overhaul for the C# automation engine. Version 4.2.1 finalizes the **"Pure Chained" Fluent API**, implements a massive performance fix for UI Predicate Hydration, and bulletproofs the `.NET 8` assembly resolution layer for external deployments.

## ⚡ Core Engine & Hydration (Critical Fix)
* **Pre-Filtered UI Predicates:** Fixed a severe scoping issue where evaluating a custom `_Filter` predicate on Loadable Components (like Doors and Windows) would aggressively iterate every Family Instance in the model. The engine now strictly honors the `[RevitElements(Category="...")]` attribute *before* applying your custom C# predicate, resulting in lightning-fast UI dropdowns.
* **Native Name Matching:** Predicates can now safely and consistently utilize the `.FamilyName()` extension (e.g., `fi.FamilyName().Contains("Single-Flush")`) to accurately filter specific loadable types without having to deal with Revit's obscure `fi.Name` vs `fi.Symbol.FamilyName` complexities.

## 💎 UX Polish & Data Visualization
* **Theme Support Restored:** Re-integrated Light, Midnight, and the beloved high-contrast Eclipse themes across the architecture.
* **Dynamic Recharts:** The Analytics Graphing widgets now dynamically parse custom `object` properties (like `Level`, `TotalArea`, etc.) generated by your REPL projections instead of enforcing rigid data schemas. 
* **Filtered CSV Extraction:** The "Export CSV" function in the Analytics table now strictly respects the UI search/filter state. You can dynamically execute `GetElements<FamilyInstance>("Doors").Table()` to visually list thousands of doors, use the frontend search box to isolate exactly what you need (e.g., "Single-Flush"), and click Export to download perfectly filtered CSV datasets seamlessly.

## 🛠️ The "Pure Chained" Fluent API 
Standardized the entire C# Extension suite into uniform, predictable Nouns and Verbs:
* Dropped legacy `Get...` prefixes for sheer purity: `GetFamilyName()` -> `FamilyName()`, `GetNativeProperties()` -> `ReflectionProperties()`.
* Eradicated legacy global diagnostic wrappers (like `Peek(el)`) from the core engine in favor of flawless extension chaining (`Selection[0].Peek()`).
* Clarified IntelliSense XML tooltips for `.Matches("...")` and `.WhereMatches("...")` to explicitly document their fuzzy substring logic against both Type Names AND true Family Names.

## 🏗️ Autodesk Deployment Resiliency (DLL Hell Fix)
* **.NET 8 SDK Pinning:** The `global.json` and all automated workspace-generation scaffolds (VS Code Extension & Python Server) have been strictly locked to the `.NET 8.0.x` feature band, preventing global SDKs from secretly corrupting the build runtime during compilation.
* **Assembly Collision Resolved:** Downgraded all `Microsoft.Extensions` references in `RServer.Addin` and `CoreScript.Engine` back to `v8.0.1`. This perfectly aligns with Revit 2025's native `.NET 8` AppDomain, completely mitigating the `Version=8.0.0.0` missing-assembly crash for users running heavily modded Revit instances.
